# Money Tracker - Automated Build Releases

This repository contains automated APK build artifacts and releases for the [Money Tracker](https://github.com/mnalwafi/money-tracker) app.

### Latest Builds
Builds are automatically compiled and published here by GitHub Actions CI/CD workflows upon each push to the main repository.

- **Debug APK**: Generated on each commit for testing.
- **Release APK**: Signed and optimized production builds.
